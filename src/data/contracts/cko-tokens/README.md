# CKO Universal Content Design Tokens v1.0

Design-token package para:
- artigos/conteúdos;
- flashcards;
- infográficos;
- simulados de concursos;
- casos clínicos;
- e-books;
- guias de bolso;
- guias de estudo.

## Estrutura
- `tokens/`: fonte canônica em JSON
- `dist/`: CSS, SCSS e TypeScript
- `schemas/`: JSON Schema
- `docs/`: especificação
- `preview/`: gallery visual
- `reports/`: validação e hashes

## Baseline visual
- Navy institucional: `#1A3E74`
- Display: Nunito Sans
- Body: Inter
- Light + Dark
- Comfortable + Compact
- A4 + Letter
- Touch target mínimo: 44px
- Body mínimo: 16px
