# CKO M3 — Normative and Reference Basis v0.3.0

## Status

PRE_CANONICAL / TEST / no full ISO conformance claim.

## Primary normative basis

1. **ISO/IEC 11179-3:2023** — registry common facilities and generic registry-item concepts.
2. **ISO/IEC 11179-3:2023/Amd 1:2026** — current amendment concerning Item Mapping.
3. **ISO/IEC 11179-35:2023** — extension for registration of models and associated metamodels.
4. **ISO/IEC 11179-31:2023** — supplementary basis for later Master Data/data-specification metamodel refinement.

## Open reference architecture

5. **OMG MOF 2.5.1** — reference for explicit model/metamodel layering.  
   CKO uses MOF as an architectural reference; it does not claim MOF conformance in this package.

## Executable schema basis

6. **JSON Schema Draft 2020-12** — used to implement the M3 executable grammar and validate M2 definitions.

## Copyright / access rule

The package does **not** reproduce the full ISO texts. Public ISO metadata and official URLs are preserved as
initial evidence. If the project owner lawfully possesses a licensed copy, the local extractor may ingest that
copy into the controlled Evidence workspace subject to the license/access policy. A licensed copy must not be
silently treated as redistributable.

## Conformance language

- `REFERENCE_ONLY`: architecture/reference use only.
- `PARTIAL`: alignment supported by public official metadata but not clause-by-clause proof.
- `CLAUSE_VALIDATED`: only after exact source clauses have been lawfully captured, atomized and validated.
- `FULLY_VALIDATED`: reserved for complete applicable requirement mapping with zero blocking gaps.
