# Metamodel Reference Basis

CKO's M3/M2/M1/M0 structure is an architectural adaptation, not a claim of clause-level ISO/MOF conformity.

Reference concepts:
- OMG MOF / UML four-layer metamodel hierarchy: meta-metamodel (M3), metamodel (M2), model (M1), instances (M0).
- ISO/IEC 11179-3:2023 metadata registry common-facilities metamodel and generic registry-item concept.
- ISO/IEC 11179-35:2023 model registration including models and associated metamodels.

Licensed standards are not reproduced here. Only public metadata/concepts are used unless an authorized local source is present.
