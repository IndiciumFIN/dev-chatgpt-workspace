Workflow de preenchimento

  1. Manual de Identidade (00) — leia primeiro, valide os tokens.
  2. Componentes de Site (01) — confirmar que Shell/Hero/Breadcrumb já existem em src/components/site/.
  3. Componentes Editoriais (02) — para cada CMP-*, preencha os slots TODO do .schema.json e valide o HTML.
  4. Contratos canônicos (03) — substitua os placeholders no JSON Schema por valores reais; promova status CANDIDATE → SOURCE_QUALIFIED → ASSURED → RELEASED via gate humano.
  5. Templates/perfis (04) — para cada perfil, defina a sequência de CMP-* e os contratos obrigatórios.
  6. Gates obrigatórios: sources → rights → a11y → privacy → human. Sem human approval, status permanece HOLD_HUMAN.
