# PMO — catálogo de diretorias por projeto

Este diretório representa a camada de planejamento e controle operacional versionado no GitHub. Cada projeto deve possuir escopo, WO, fontes, atividades, journal e alçadas **separadas**.

- [WU-TRIB — PMO de atividades da V1](WUTRIB/README.md): 26 lacunas da comparação normativa, 30 grupos de testes planejados e sete gates humanos, com agente determinístico e execução controlada no GitHub Actions.

**Governança:** uma WO documenta desde o planejamento; a admissão pela autoridade do Kernel e as decisões humanas são etapas distintas. Nenhum agente deste diretório pode assinar aprovação, homologação, retificação fiscal ou liberação de produção.

**Estado inicial:** branch candidata, sem merge para a branch principal e sem alteração de outros sistemas ou projetos.
