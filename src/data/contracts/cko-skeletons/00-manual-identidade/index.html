Bem-vindo ao Manual de Identidade do CKO

Este manual é a fonte única de verdade visual para todos os componentes e templates do sistema. Qualquer desvio deve ser justificado via contrato design_adapter e aprovado por gate humano.

Regras centrais do DS

  • Sem CSS paralelo. Toda cor, fonte ou espaçamento deve referenciar var(--color-*) ou var(--font-*).
  • Sem componentes concorrentes. Se já existe Shell, Hero ou Breadcrumb oficial, reutilize.
  • Modo escuro e alto contraste são nativos. Use html[data-theme=dark] e html[data-contrast=high].
  • Mobile-first. Toda página deve reflowar em ≤770px e ≤430px.
  • Print-friendly. Bloquear .cko-actions, .cko-sidebar, .cko-tools em @media print.
