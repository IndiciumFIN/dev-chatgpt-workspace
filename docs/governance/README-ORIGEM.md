# Governança do workspace e da publicação

## Objetivo

Estabelecer uma cadeia de governança para que nenhuma atividade, conteúdo,
template, artefato, preview ou deploy avance sem:
- ordem de trabalho (WO) homologada
- política ativa
- metamodelo e dicionários controlados
- manifesto
- kernel de decisão
- evidência e ledger
- aprovação formal

## Base do repositório

O repositório já possui camadas que são fundamentais para governança:
- `contracts/`: contratos e escalas de validação
- `registers/`: evidência e decisões
- `audit-evidence/`: rastreio e evidência executiva
- `scripts/`: validadores e gates
- `src/`: modelo do domínio e projeções do front-end
- `docs/`: contexto, pendências e normas

## Regra final

Nenhuma publicação ocorre sem:
- ordem de serviço / WO
- política ativa
- kernel de decisão
- manifesto aprovado
- evidência registrada
- preview aprovado
- deploy controlado

## Alinhamento

- COSO: governança, risco, contingência, controle, monitoramento
- COBIT: alinhamento estratégico, gestão de risco, dados, monitoramento
- COSO IA: supervisão humana, explicabilidade, rastreabilidade, monitoramento
