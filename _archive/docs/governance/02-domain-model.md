# Modelo de domínio

## Visão geral

O domínio é composto por entidades e regras que definem o que existe no sistema
e como essas entidades interagem.

## Camadas

### 1. Dados de origem
- fontes externas
- registros brutos
- fontes e metadados

### 2. Dados normalizados
- canonização
- transformações
- normalização de campos

### 3. Dados governados
- dicionários e master data
- políticas ativas
- normas
- contratos de template

### 4. Dados de execução
- WorkOrder
- manifesto
- evidence ledger
- preview
- deploy

## Regras

- domínio não é UI
- domínio não é publicação direta
- domínio precisa de contrato e evidência
